# 위장 시험 대결 — 사내 테스트 프로토타입

학교 시험 컨셉의 2인 대결. 모든 문제는 **정답 보기 + 오답 보기** 구조이고, 바보는 **오답을 찾아 고르면 안전**.
**정답을 고르면 그 과목 점수가 올라가고**(똑똑함 들통), 6교시가 끝났을 때 **총점이 낮은 사람이 승리**(높은 사람은 출근).

## 실행

```bash
npm install
npm start                 # 정식 속도 (약 16분)
PHASE_SPEED=10 npm start  # 테스트용: 10배 빠르게 (약 1.6분). Windows: set PHASE_SPEED=10 && npm start
NO_PATROL=1 npm start     # 테스트용: 선생님 순찰 자동 발동 끔 (자동화 테스트가 순찰에 막히지 않게)
```

| 화면 | 주소 | 용도 |
|---|---|---|
| 플레이어 1 / 2 | `/player.html?role=1`, `?role=2` | 대결용 PC (키보드 1~4로도 선택 가능) |
| 관전 화면 | `/spectator.html` | 큰 모니터용 — 현재 문제, 성공/실패 이유, 오답 공개, 방해 이벤트 |
| 진행 요원 | `/admin.html` | 시작 / **봇과 시작(혼자 테스트)** / 다음 구간 / 리셋 / 로그 |

**혼자 테스트하려면**: `/admin.html`에서 "봇과 시작" → 내 화면은 `/player.html?role=1`, 구경 화면은 `/spectator.html`.
봇은 1.2~3초 고민하고 20% 확률로 정답을 골라버립니다(`gameLogic.js`의 `botMistakeRate`).

## 시간표 (총 약 16분)
워밍업 30초(가위바위보, 점수 없음) → 1교시 국어 → 2교시 영어 → **3교시 수학(방해 카드·안전/터보 등장)** → 4교시 사회 → 5교시 과학 → 6교시 예체능·종합 (교시당 150초, 사이마다 5초 쉬는 시간에 점수·다음 교시 안내)

| 과목 | 문제 유형 (오답 하나를 찾기) |
|---|---|
| 국어 | 글자색과 이름이 같은 것은? (색: 빨강/파랑/초록) |
| 영어 | 철자가 맞는 단어는? |
| 수학 | 같은 수 표기 / 홀수·짝수 / n의 배수 |
| 사회 | 갈 수 있는 길은?(막힌 길) / 수도가 맞는 것은? |
| 과학 | 물에 뜨는 것은? / 자석에 붙는 것은? / 곤충은? / 뜨거운 것은? / 태양계 행성은? (전문 지식 없이 한눈에 보이는 생활 상식) |
| 예체능 | 외친 것은?(가위바위보) / 화살표가 가리키는 쪽은? |

## 시스템 요약
- **고민하면 들통**: 문제가 뜬 뒤 **3초까지는 벌점 없음**, 3초를 넘기면 초과 1초당 +6점(최대 +30)이 그 과목에 쌓임 — 안전한 답을 골라도 마찬가지. 5초를 넘기면 정답을 골라버린 것으로 처리. (순찰로 멈춘 시간은 제외, 화면의 타이머 바가 3초 지나면 빨갛게 변함)
- **선생님 순찰 (2교시~, 교시당 1번, 6교시 2번)**: 3초간 "멈춰!" — 이때 아무 버튼이나 누르면 컨닝 적발(+15점). 가만히 있으면 안전하고, 순찰 중엔 제한시간도 멈춤
- **스택 1개의 쓰임 (3교시~)**: 방해 3종 중 하나 던지기 / 족보 보기(이번 문제 오답 하나 힌트) / 방어(방해가 날아올 때만)
  - 낙서: 상대 화면이 색으로 뒤덮임 → 다른 색 30번 연타해야 탈출
  - 잉크: 상대 문제·보기가 2.5초간 흐려짐
  - 시간단축: 상대 남은 시간이 2.5초로 줄어듦
  - 방어(스택 1, 예고 1.8초 안에)는 3종 모두 막음
- 문제 풀기 전 안전/터보 선택(3.5초): 안전=감점·보상 ↓, 터보=감점·보상 ↑
- 내가 정답을 골라 들키면 상대가 방해 스택 +0.5 (3교시~)
- 4·5·6교시에 돌발 쪽지시험(양쪽 동시 출제)이 자동 발동
- 끝나면 행동에 따라 **칭호**(철벽 방어 / 생각 많은 모범생 / 터보 중독자 / 순찰에 움찔한 사람 …)
- 경고: 상대보다 40점 이상 뒤질 때
- **블라인드 피날레 (6교시)**: 점수가 서버에서부터 비공개(플레이어·관전 화면 모두 ???, 관제 화면만 열람). **마지막 30초는 모든 점수 2배**(정답 골라버림·고민 벌점·순찰 적발 전부). 끝나면 두 점수가 카운트업으로 공개된 뒤 승패 발표

## 숫자는 전부 추정치
`gameLogic.js` 상단 `CONFIG`/`CARDS`: 과목별 점수(18/24/30), 제한시간, 교시 길이, 경고 기준 등. 관제 화면의 **로그 다운로드**로 테스트 결과를 보고 조정하세요.

## 화면 스타일
코믹·고채도 테마(굵은 남색 외곽선 + 납작한 원색 + 오리지널 표정 캐릭터 + 만화 효과음 "들켰다!" 등). 테마는 각 html 파일의 `<style id="comic-theme">` 블록에 모여 있어서 색을 바꾸려면 거기서 `--ink`와 색상값만 고치면 됩니다. 기능/ID는 건드리지 않고 덮어쓰는 방식입니다.

## 한계
- 발판/버튼 물리 입력, 사운드, 체키 사진 출력은 없음 (화면 버튼/키보드로 대체)
- 서버 상태는 메모리 저장 — 재시작 시 초기화
- 테스트용: `admin:patrol` 소켓 이벤트로 순찰을 즉시 발동할 수 있음 (UI 버튼은 없음, 실제 진행은 자동)
- 문제 은행(영어 단어, 수도, 원소 등)이 작아서 15분 안에 같은 문제가 반복될 수 있음
