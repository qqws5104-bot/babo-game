# 위장 게이지 대결 (가제) — 사내 테스트 프로토타입

"똑똑한 사람이 일해야 하는 나라"에서, 반전 카드를 수행해 위장 게이지를 지키다가 먼저 바닥난 쪽이 "출근"하는 2인 대결 게임. 사내 밸런스 테스트용 프로토타입입니다.

물리 하드웨어(발판 3개 + 버튼 4개)는 아직 없으므로, 이 버전은 **화면 버튼 클릭**으로 대체합니다. 반응속도/밸런스/게이지 시스템 검증이 목적이고, 발판의 신체적 재미(헛발질)는 이 프로토타입 범위 밖입니다.

## 실행 방법 (같은 사무실 네트워크 기준)

```bash
git clone <이 저장소 URL>
cd foolgame
npm install
npm start
```

서버가 뜨면 터미널에 다음이 출력됩니다:

```
위장 게이지 대결 서버 실행 중: http://localhost:3000
  플레이어1: http://localhost:3000/player.html?role=1
  플레이어2: http://localhost:3000/player.html?role=2
  관제 콘솔: http://localhost:3000/admin.html
```

- **메인 컴퓨터**(서버를 켠 컴퓨터)에서 관제 콘솔(`/admin.html`)을 엽니다.
- **대결용 컴퓨터 2대**에서는 `localhost` 대신 메인 컴퓨터의 **로컬 IP**로 접속해야 합니다.
  - 메인 컴퓨터 IP 확인: macOS/Linux `ifconfig | grep inet`, Windows `ipconfig`
  - 예: `http://192.168.0.12:3000/player.html?role=1`, `http://192.168.0.12:3000/player.html?role=2`
- 세 대 모두 같은 와이파이/네트워크에 연결되어 있어야 합니다.

## 관제 콘솔 사용법

- **세션 시작**: 워밍업(2분)→1막(5분)→2막(6분)→보스전(5분) 순으로 자동 진행
- **다음 구간**: 현재 구간을 건너뛰고 바로 다음 구간으로 (테스트 시간 단축용)
- **리셋**: 게임 상태 전체 초기화
- **게이지 강제 조정**: 특정 상황(경고모드, 발각 직전)을 빠르게 재현할 때 사용
- **다음 카드 강제**: 특정 카드 조합만 집중적으로 테스트하고 싶을 때 사용
- **로그 다운로드**: 세션 전체 이벤트(성공/실패/간섭/발각)를 JSON으로 저장 — 테스트 후 밸런스 리뷰용

## 지금 이 프로토타입에 반영된 것

- 입력카드 5종(가위바위보/좌우/색상단어/숫자/청각이중부정) + 보스전용 이중반전
- 게이지 100 시작, 난이도별 차등 감점(-10~-25), 콤보 5연속 시 +10 회복, 30 이하 경고모드
- 간섭(방해카드 투척) — 예고 후 유예시간, 방어 시 스택 소모, 방어 실패 시 다음 라운드가 해당 카드로 강제
- 방어 성공적으로 뚫리면(=상대가 강제카드를 맞춰버리면) 던진 쪽 스택 손해(역관광 페널티)
- 패자는 발각 즉시 "출근 확정" 결과화면, 승자는 "연차 승인" 결과화면

## 아직 반영되지 않은 것 (다음 단계)

- 변형카드 중 ⑥지연반전/⑦선행반전 (타이밍 기반이라 별도 설계/실측 필요)
- 경고모드 진입 시 시각/사운드 연출(형광등 오피스 톤 전환, BGM 템포업 등) — 현재는 화면 테두리 점멸만 최소 구현
- 실제 발판/버튼 하드웨어 연동
- 뉴트로 톤 비주얼 디자인 (현재는 기능 검증용 최소 스타일)

## 숫자는 전부 추정치입니다

게이지 감점폭, 스택 충전량, 유예시간(1.8초) 등은 논리적으로 설계했지만 실측된 값이 아닙니다. `gameLogic.js` 상단 `CONFIG` 객체에서 쉽게 조정할 수 있습니다. 사내 테스트 후 "1막이 너무 가혹했다" 같은 피드백이 나오면 이 숫자부터 조정하면 됩니다.
